## 변경한 페이지의 시각화 설계

### 1장 · 지향점을 먼저 선언

표기: AI와 함께 일하기 #3.
대형 타이포 두 줄: ‘가장 담대하게,’ / ‘인공지능을 극한까지 활용하는 사람’.
설명 문단 없이 핵심 문구로 시작한다. 뒤의 두 장에서 이 태도가 필요한 이유를 설명한다.

### 2장 · 모델의 발전: 하방과 상방

한 화면 안에 두 개의 수평 레인을 놓고, 과거에서 새 모델로 이동하는 방향을 공유한다. 상단 레인은 상방, 하단 레인은 하방이다. 각 레인의 도달 위치가 위로 향하는 화살표로 변화 방향을 표현한다. 두 레인에 같은 색을 다음 장까지 유지한다.

- 상방 / 수행 범위: 이전에는 어려웠던 일 → 적절한 맥락·도구·지시 아래 새롭게 해내는 일.
- 하방 / 안정성: 가끔 실패하고 손봐야 했던 일 → 더 일관된 결과, 줄어드는 개입.
- 시각적으로 상방의 영역 확장과 하방의 기준 상승을 동시에 보여준다. 수치 축·배율·확률은 붙이지 않는 개념도다. 서로 다른 개념을 하나의 정량 척도로 표현하지 않는다.
- 하방은 무오류나 모든 과업에서의 보장된 최저 성능을 뜻하지 않는다. 특정 업무에서 실패·편차·개입 필요가 실제로 줄었는지는 직접 확인한다.

### 4장 · 두 발전 방향을 내 활용 방식으로 연결

2장의 상방·하방 레인과 색을 그대로 이어받아 각각 ‘내가 해야 할 실험’으로 변환한다.

- 상방 → 더 어려운 일 / 더 넓은 방식으로 맡기기. 예: 내가 Notion 내용을 정리해 입력 → 접근 가능한 원문·스크린샷과 목표를 주고 맥락 파악부터 맡기기. 결과와 확인에 필요한 개입을 본다.
- 하방 → 기존에 자주 손보던 일 다시 맡기기. 같은 완료 기준을 유지하면서 실패와 수정·검토 부담이 얼마나 달라졌는지 본다.
- 하단 종합 문구: ‘익숙한 일에는 내 시간을 덜 쓰고, 새롭게 가능한 일에는 더 크게 도전합니다.’
- 8장은 이 중 맥락 준비의 위임을 실제 작업 순서로 확대하는 구체 사례다. 4장에서는 방향과 짧은 예시만 보여준다.
- 다음 장의 ‘미친 척하고, 정말 어려운 일을 시켜보세요’가 앞선 논리에서 자연스럽게 도출되게 한다.

### 10장 · 위임과 사고력에 대한 질문

9장 ‘시간과 어텐션’ 뒤, 11장 ‘중요한 판단’ 앞에 배치한다.
대형 질문: ‘경영진은 실무를 직접 하지 않으니, 사고력이 퇴화한 걸까요?’
하단 보조 질문 하나: ‘더 많이 맡긴 뒤, 나는 어떤 판단을 더 많이 하고 있나요?’
설명형 카드나 뇌 이미지는 넣지 않는다. 경영진의 위임은 사고 활동의 종류를 생각하게 하는 비유이며, 인지 저하가 없다는 과학적 근거로 제시하지 않는다. 다음 장에서 방향 선택·결과 평가·개입점 선택으로 답한다.

## 전체 흐름

- 1–5장: 담대한 인재상 → 모델의 하방·상방 발전 → 사용자의 과업 난도 갱신 → 활용 방식 → 어려운 일에 도전하라는 선언.
- 6–9장: 더 넓게 맡기는 의미, 설계와 맥락 준비의 위임, 시간의 가치.
- 10–11장: 위임과 사고력에 대한 질문 → 중요한 판단을 연습한다는 답.
- 12–16장: 실제 세션 → 실패 해석 → 재시도 → 스킬 축적 → 새 모델에서 다시 시험.
- 17–18장: AS-IS/TO-BE 토론과 마무리.

### 추가한 3장 · 모델 발전과 사용자 과업 난도

가로축은 모델의 발전, 세로축은 맡기는 일의 난도. 파란 상방 곡선과 청록색 안정적 위임 경계 위에 사용자의 과업 난도를 주황 계단선으로 표시한다. 기존 난도를 유지하는 회색 점선과 대비한다. 모델의 발전이 자동으로 사용자의 활용 향상이 되지는 않으며, 시도와 검토를 통해 맡기는 범위를 갱신해야 한다는 메시지다. 실제 모델 성능의 측정값이 아닌 개념도다.
