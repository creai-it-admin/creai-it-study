# Phase 1 리허설 — 2026-09-08

대상: localhost:3000 개발 서버, weekNo=0 리허설 회차.
기준: AI_Study/outputs/2026-09-06_앱_Phase1.md 16절.
Codex 내부 브라우저에서 운영진 계정으로 콘솔·참가자 화면·고정 장표 탭을 조작했다.
사용자가 Whale에서 별도 참가자 계정으로 로그인했고 콘솔에서 두 번째 출석과 폼 접속을 확인했다.
Whale 네이티브 조작 연결은 timeout/pipe closed로 실패했다. 아래에서 직접 확인과 미검증을 구분한다.

| 단계 | 결과 | 관찰 |
| --- | --- | --- |
| 1. 두 계정 로그인 | 부분 확인 | 운영진 콘솔 접근 성공. 별도 참가자 로그인은 사용자 완료 응답과 콘솔 출석 2명으로 확인. 참가자 화면의 운영진 접근 차단은 미검증. |
| 2. PDF 업로드 | 확인 | 1주차 PDF를 브라우저 파일 선택으로 업로드. 새 Storage URL 반영과 11장 렌더링 확인. |
| 3. 시작 → 장표 | 확인 | 대기 화면이 장표 화면으로 자동 이동. 실제 회차는 시작하지 않음. |
| 4. 독립 페이지 이동 | 확인 | 참가자 화면 탭 2/11, 고정 장표 탭 1/11 유지. 두 탭은 같은 운영진 계정. |
| 5. 2부 → 폼 | 확인 | 폼 자동 이동, 여섯 칸, 경과/40:00 표시. 엄밀한 3초 이내 측정은 수행하지 않음. |
| 6. 장표 재방문 | 확인 | 2부에 /deck 직접 진입 후 여러 폴링 주기가 지나도 장표에 머무름. |
| 7. 입력·새로고침·오프라인 | 부분 확인 | 첫 칸에 테스트 표식을 입력하고 즉시 새로고침. 표식 복구, 추가 입력 없이 저장됨 및 콘솔 반영 확인. 여섯 칸 수정 저장 확인. 네트워크 차단/복구는 미검증. |
| 8. 제출 | 부분 확인 | 기존 제출물의 여섯 칸 재제출, 저장됨, 콘솔의 여섯 답변 반영 확인. 별도 참가자의 첫 제출/제출 인원 증가 미검증. |
| 9. 공유 | 부분 확인 | 공유 닫힘 안내 및 자기 제출물 표시, 열기 후 안내 해제, 여섯 답변 표시 확인. 서로 다른 계정 간 타인 제출물 차단/공개는 미검증. |
| 10. 휴식·3부 | 확인 | 휴식 경과/10:00, 3부 경과/30:00 표시 및 마지막 구간에서 다음 버튼 비활성화 확인. |
| 11. 종료 | 확인 | 콘솔이 /admin으로 복귀하고 리허설 끝남 표시. 참가자 화면 탭이 /home으로 자동 이동. |

기존 답변 여섯 칸은 테스트 전 내용을 메모리에 보관해 테스트 후 원문으로 재제출했고, 저장됨과 콘솔 원문 복원을 확인했다. 재제출 시각은 갱신됐다. 리허설 PDF는 새 업로드 파일로 교체됐다.
리허설 초기화는 답변을 지우지 않는 PRD 설계이며 이번 실행에서는 초기화하지 않는다.

## 판정

직접 수행한 흐름에서는 차단 오류를 발견하지 않았다. 전체 리허설 합격으로 판정하지는 않는다. 실제 오프라인 복구, 별도 참가자의 첫 제출, 계정 간 공유·권한 검증이 남았다. 앞선 16개 회귀 테스트와 이번 브라우저 리허설은 검증 범위가 다르다.

종료 상태: 리허설 closed, 1~4주차 scheduled. 테스트 표식은 제거했고 기존 답변 본문은 복원했다.
